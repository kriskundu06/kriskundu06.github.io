[ Work ]

Things I’ve built.

A RAG-based due diligence platform for company financials. Upload financial PDFs and it calculates debt, assets, and liquidity. An Ask AI feature, powered by Gemini 3.5 Flash Lite, answers questions from the uploaded documents.

Source on GitHub

A PPO-based portfolio manager with a custom Gymnasium environment that shifts allocation across the S&P 500, NASDAQ, Gold, Oil, and NIFTY 50. On 2023–2025 backtesting it returned 66.4% in total, 19.9% CAGR, and a 1.87 Sharpe ratio. FinBERT sentiment experiments and FastAPI endpoints feed a React and TypeScript dashboard on Render and Vercel. I’m still adding more features.

Source on GitHub

A machine learning system that predicts cyclone trajectories over the North Indian Ocean, covering the Bay of Bengal and the Arabian Sea. It learns from historical cyclone data to forecast future storm positions with Random Forest and XGBoost. An OpenStreetMap view shows the predicted paths, and a FastAPI backend serves the forecasts.

Source on GitHub

An interactive arena where attackers and defenders go head to head against an AI system. The biggest lesson wasn’t about better prompt engineering.

Prompt guardrails, regex filters, and DLP slow attackers down, but true resilience comes from architecture. An LLM cannot leak a secret it never possesses.

Source on GitHub

A customer sentiment platform for text and CSV reviews. It runs a Transformer model over the reviews and shows the results in interactive charts so you can explore what customers are saying.

Source on GitHub

A movie recommendation system built on the Kaggle TMDB 5000 dataset. Pick a movie and the app suggests similar ones, using a Streamlit interface over a Scikit-learn model.
